# WCAG Accessible Component Library

A React component library built to WCAG 2.1 AA standards — keyboard navigation, 
semantic HTML, ARIA attributes, and color contrast compliance across all components.

## Features
- Fully accessible interactive components (buttons, modals, forms, etc.)
- Automated accessibility auditing via jest-axe in the test suite
- Built with TypeScript for type-safe usage
- Documented usage notes and WCAG compliance rationale per component

## Tech Stack
React.js · TypeScript · jest-axe · Testing Library · Vite

## Getting Started
\`\`\`bash
npm install
npm run dev
\`\`\`

## Running Tests
\`\`\`bash
npm run test
\`\`\`
